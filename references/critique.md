# 论文读法与它的软肋

来源：Nam, Yoon, Pan, Wang, Meng, Ranganathan, Pfister. *ScientistTwo: Pioneering the Human Knowledge Frontier with Autonomous AI*. arXiv:2609.19644, 2026-09-17. Google Cloud AI Research + University of Waterloo。项目页 https://scientist-two.github.io/

---

## 1. 它到底做了什么

一个六组 agent 的闭环：Idea Generator → Evaluator（子集筛）→ Analyzer（消融精修）→ Writer → Peer-Review → Meta-Review，回环到稿子过线为止。任务是**问题驱动**的：人类给论文 + 代码 + 指标，它在原 SOTA 上做出可归因的改进并写成稿。

结果（107 题，来自 NeurIPS 2025 / ICLR 2026 / ICML 2026 Spotlight）：

- 86/107（80.4%）超过人类 SOTA，平均相对提升 25.2%
- ScholarPeer 7.5/10、接受率 91.9%
- Stanford Agentic Reviewer（held-out）5.7/10、接受率 72.1%
- 单篇 ~2.5 天、~$3,765
- 人工评审（9 人 / 33 篇）：独立评 3.7/5；与人类论文对比 3.0 = 打平，其中**方法严谨性 2.9 略输人类**，实验广度略赢

## 2. 值得抄的五条（本 skill 保留的核心）

1. **子集先筛。** 想法先在代表性切片上跑，过了才花全量算力。这是让闭环在经济上可行的唯一原因。
2. **消融是归因闸门，不是附录。** 论文里 DMC-TeCh 的增益来自 EMA + label smoothing，Ablation Critic 直接拒收，哪怕它在 6 个指标里赢了 5 个。全文最有价值的一条纪律。
3. **rebuttal 用新实验。** 被质疑 → 规划实验 → 写代码 → 跑 → 改表格。区别于"改措辞糊过去"。
4. **结构约束优于提示词禁令。** 论文对 AutoSOTA 的分析很到位：AutoSOTA 也在 prompt 里写了红线条款（不许改评测、不许跨指标交易），但实测两例都失效；ScientistTwo 改成"重跑复现 + 协议不可变 diff + 方法-代码对齐审计"这类结构性检查才挡住。这条直接决定了本 skill 的 G7 设计。
5. **每个循环都有界。** 局限 16 轮、想法 4 轮、工程补救 2 轮、消融精修 1 轮、评审 2 轮、元审 1 轮。全都写死了上限，这是工程可控性的来源。

## 3. 它没证明什么（别跟着吹）

**① 91.9% 接受率基本是自己给自己打分。** 论文明确承认 ScholarPeer 既是成稿的评审器、又是评测指标（in-distribution）。真正的 held-out 数字是 Stanford Agentic Reviewer 的 5.7/10、72.1%。作为对照，被接收的人类论文在这个评审器上是 ICLR 5.2、NeurIPS 5.5、ICML Spotlight 6.1。也就是说：**领先幅度 0.2–0.5 分，属于"能过线"，不是"超越人类"。** "超过人类论文平均分"这个说法没撒谎，但听感比事实强得多。

**② 基线对比不齐。** 表 2 里各框架的论文数从 2 篇到 21 篇不等（ScientistTwo 是 86 篇），题目集不同、难度不同，接受率并排比本身意义有限。表 4 跟 AutoSOTA 比增益时，论文自己也承认"不是同一硬件上的 head-to-head"，而且增益数字是用 Gemini 解析主表 10 次取平均——这是有噪声的估计，不是测量。

**③ 人工评审的结论被摘要弱化了。** 摘要在说 expert-level、publishable；人工评审的实际结果是"总体打平、方法严谨性不如人类、独立评分 3.7/5（勉强正向）"。9 个评审、33 篇，样本也不大。

**④ 跨 venue 一致性差。** 整体平均增益 25.2%，但拆开看：NeurIPS 7.0（中位）、ICLR 2026 只有 2.2（中位）。ICLR 那批题它还比 AutoSOTA 差。这说明能力对题目类型高度敏感，25.2% 这个均值被少数大涨的题拉高了。

**⑤ 天花板明确。** 论文自己写：达不到 spotlight/oral 那种概念级突破；本质是"在给定 baseline 上做局限驱动的局部方法改进"。它改善不了"这个问题选错了"。

**⑥ 成本劝退。** $3,765/篇。对独立研究者是硬门槛，对工业实验室是零花钱。这个不对称本身就值得记一笔。

**⑦ 没有真实投稿证据。** "publishable" 的定义是 AI 评审过线，不是任何真实会议接收。评审器和被评审者是同一代模型的近亲，自偏好偏差无法排除。

## 4. 结论：当流程用，别当能力承诺

这套东西的工程价值在**流程约束**，不在模型能力。它把「先定位局限 → 提机制 → 子集证伪 → 全量确认 → 消融归因 → 挨批 → 补实验」这条人类科研的规矩变成了不可跳过的状态机。这个价值是真实的，而且跟算力无关——你就算手动做实验，按这个顺序做也比按"先跑个 SOTA 再说"做靠谱。

反过来说，如果你指望它替你想出范式级的新方向，那是用错了工具。论文自己都不这么宣称。

## 5. 本 skill 相对论文的偏离（明确记账）

| 改动 | 理由 |
|---|---|
| 加 G0「值不值得做」三问 | 论文没有前置筛选，导致它花 $3,765 去解一些文献检索就能回答的问题。这是它成本失控的根源。 |
| 加「双评审器」（held-out 校验） | 直接对冲 ①② 的 in-distribution 漏洞。论文自己吃了这个亏。 |
| 要求 3 seed + 显著性判定 | 论文未公开 seed 协议。单 seed 的"提升"在多数任务上会被方差吃掉。 |
| 想法数定为 ≥6（论文只说 N） | 论文未公开 N 与 K。6 是保证 4 轮不空转的经验值。 |
| 局限模板强制带「可观测现象 + 干预方式」 | 论文的局限抽取偏自由文本，容易滑成"还有提升空间"。加结构是为了让 G1 可判。 |
| 增加 A4 消融（通用旋钮复现） | 论文是事后发现了 DMC-TeCh 的问题。把它变成每个方法都必须跑的固定项，比等 Critic 事后发现便宜。 |
| 四档降级（A/B/C/D） | 论文假设有完整算力与执行环境。现实中多数用户没有，硬跑只会产假数据。 |
| 强制 `TBD(blocked:)` 语法 | 防止"悄悄填空"。 |
| 预算闸门（80% 暂停） | 论文只在 limitation 里承认贵，没有运行时的熔断。 |
